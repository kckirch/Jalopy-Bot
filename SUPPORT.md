# Support

## Bugs and feature requests

Use the repository's issue forms for reproducible bugs and feature ideas.
Please include the relevant Node.js version, scraper engine, logs with private
data removed, and clear reproduction steps.

This is a volunteer-maintained project, so response times are not guaranteed.

## Security and private data

Do not use public issues for vulnerabilities, credentials, Discord identities,
or production database contents. Follow [SECURITY.md](SECURITY.md) instead.

## Using the hosted bot

Visit [JalopyBot.com](https://jalopybot.com) for the hosted inventory
experience. Repository issues are intended for project defects and development
questions, not urgent vehicle availability requests.
